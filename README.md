# Flyrank.ai

![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)
![Node.js](https://img.shields.io/badge/Node.js-LTS-green.svg)

A modern platform for AI-assisted development tracking and analytics.

## Prerequisites

- **Node.js** (LTS version)
- **Git**

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/harshit3003/Flyrank.ai.git
   cd Flyrank.ai
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the project locally:
   ```bash
   npm run dev
   ```
