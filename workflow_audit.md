# Workflow Audit

## 1. Recurring Tasks

| Task | Classification | Rationale |
| :--- | :--- | :--- |
| **Writing initial boilerplate code for new features** | Fully automate | AI is incredibly fast at scaffolding basic structures, saving me time for actual logic. |
| **Debugging complex logic errors in React components** | Collaborate with AI | AI helps spot hard-to-see logic flaws, but I need to guide it with my context of the app state. |
| **Reviewing Pull Requests from peers** | Just me | I need to deeply understand the codebase changes and maintain accountability without relying on AI. |
| **Writing unit tests for utility functions** | Delegate to AI with review | AI is great at generating test cases and finding edge cases, but I must verify the assertions are correct. |
| **Drafting weekly progress reports** | Delegate to AI with review | I provide the bullet points of what I did, and AI formats it into a professional, readable summary. |
| **Planning system architecture for a new project** | Collaborate with AI | I use AI as a sounding board to brainstorm trade-offs, but I make the final architectural decisions. |
| **Replying to complex technical emails** | Delegate to AI with review | AI helps set a professional tone and structure, but I need to verify all technical facts before sending. |
| **Attending team standup/sync meetings** | Just me | Requires my actual human presence, active listening, and spontaneous real-time communication. |
| **Refactoring messy legacy code** | Collaborate with AI | AI suggests cleaner patterns and modern syntax, while I ensure it doesn't break existing business logic. |
| **Generating regex patterns for data validation** | Fully automate | AI is consistently faster and more accurate at writing and explaining complex regex than I am. |
| **Reading and understanding new API documentation** | Collaborate with AI | AI can quickly summarize long docs, but I still need to read specific endpoints to understand the nuances. |
| **Updating my resume with new project skills** | Delegate to AI with review | AI can improve my bullet points with strong action verbs, but I must ensure the claims remain 100% honest. |

## 2. Target Tasks for FL-02 through FL-04

**Target Task 1: Writing unit tests for utility functions**
* **Success Definition (Done Well):** The AI generates passing tests that cover at least 90% of edge cases within 5 minutes, requiring less than 2 lines of manual correction per test suite.

**Target Task 2: Debugging complex logic errors in React components**
* **Success Definition (Done Well):** AI identifies the root cause of the bug within 2 prompts, and the suggested fix works without introducing new regressions, saving me at least 15-20 minutes compared to manual debugging.

**Target Task 3: Refactoring messy legacy code**
* **Success Definition (Done Well):** The AI successfully modularizes the target function, reducing its cyclomatic complexity while maintaining a 100% test pass rate, and the resulting code style perfectly matches our project's linting rules.
